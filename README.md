# NumPy for Machine Learning (Scikit-Learn Prerequisites)

This repository contains structured, step-by-step Jupyter Notebook notes and practical assignments focused on mastering foundational NumPy skills required for Machine Learning and Scikit-Learn workflows.

## 📌 Objectives
- Master essential array manipulations, data typing, reshaping, and indexing.
- Understand feature matrix ($X$) and target vector ($y$) configurations required by Scikit-Learn.
- Build clean, practical coding exercises demonstrating real-world ML data preparations.

## 🗂️ Topics Covered
- **Module 1:** Data Types (`dtype`) and Memory Optimization
- **Module 2:** NDArrays, Dimensions, and Essential Reshaping (`reshape(-1, 1)`)
- **Module 3:** Array Creation Routines (`zeros`, `ones`, `arange`, `linspace`)
- **Module 4:** Indexing, Slicing, and Boolean Masking
- **Module 5:** Vectorized Operations and Broadcasting
